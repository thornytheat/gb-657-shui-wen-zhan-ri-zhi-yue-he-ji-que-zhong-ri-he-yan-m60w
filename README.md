# hydrocalendar 水文站日值月合计缺重日核验

流域数据员导入多站日值，系统区分零雨与缺测，按数据版本裁决重复日，用 Decimal 计算月合计并标出不完整月份。

## 模块

- 日值采信：单位、空值、编码与坏行隔离。
- 站点日历：启停日期、闰日和当地自然日。
- 缺重日判定：零雨、缺测、重复版本与冲突。
- 月量计算：日值汇总、覆盖率与月报状态。
- 雨量补报：逐日补报与跨日累计补报两种依据分开保存，累计不摊成日值，重叠只计一次，跨月归属不足时待定。
- 跨站复核：相邻站差异与复核证据。
- 批次对账：输入、采纳、重复、隔离四账。
- 月报导出：单一 CSV 与运行证据。

## 启动

```bash
docker compose up --build
```

浏览器打开 <http://localhost:18216/>。

## 测试

```bash
docker compose exec -T app pytest -q
```

核心反例包括：零雨误作缺测、后写低版本覆盖高版本、闰年二月缺日、单位混用和同版本不同值；雨量补报另有累计被均摊成日值、重叠覆盖重复计、日值与累计不符、过期决定覆盖新决定、同笔请求重试新增观测。
